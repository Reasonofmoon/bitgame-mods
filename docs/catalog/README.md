# bitgame-mods 카탈로그 (A4 · 8페이지)

GAME MODE(bitgame-mods 0.3.0, 22 Mods + Gemini CLI 익스텐션)를 한국어로 소개하는 카탈로그입니다.

- `Bitgame Mods Catalog.dc.html` : 카탈로그 원본 (doc-page / image-slot 컴포넌트, Industry 디자인 시스템 `_ds/`)
- `Bitgame Mods Catalog.pdf` : 인쇄·배포용 PDF (GIF는 대표 프레임으로 출력)
- `assets-bitgame/` : `docs/assets`의 스크린샷과 녹화 영상(game-mode-0.2.0.mp4)에서 뽑은 GIF 3종, 저장소 QR, Galmuri 글꼴(OFL)

## 미리보기

```bash
cd docs/catalog
python -m http.server 8099
# http://localhost:8099/Bitgame%20Mods%20Catalog.dc.html
```
