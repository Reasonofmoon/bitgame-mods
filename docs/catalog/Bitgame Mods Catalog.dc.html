One rule

장식만 하는 HUD는 소음이다

bitgame-mods는 Claude Code 엔진 안에서 돌아가는 작은 훅 모듈(Mod) 모음입니다. 규칙은 하나, 모든 게임 요소는 실제 숫자를 보여 주거나, 실제 피해를 막거나, 실제 시간을 아낍니다. 순수 장식 변경은 이유가 필요합니다.

TRAP! · BARRIER! · LOOP! — 진짜로 막는다

세 가드는 도구 호출이 실행되기 전에 읽고, 위험하면 거부합니다. 거부 문구는 항상 game-… blocked this call:로 시작하고 무엇을 대신할지 알려 주며, 전투 로그와 효과음이 같은 문구로 반응합니다.

녹화 세션 0:52–1:20 · cat .env → TRAP! · git reset --hard → BARRIER! · 같은 실패 4번째 → LOOP!
Fig. 02 — 가드가 실제로 거부하는 장면 (녹화 영상에서 추출한 GIF · 인쇄본은 TRAP · BARRIER 장면)
TRAP GUARD비밀키 유출 차단명령·URL·소스의 실제 키, cat .env, echo $API_KEY, id_rsa·*.pem 읽기
BARRIER되돌릴 수 없는 명령 차단main 강제 푸시·삭제, reset --hard, clean -f, 프로젝트 밖 rm -r, npm publish, DROP TABLE
LOOP BREAKER헛된 재시도 차단같은 방식으로 3번 연속 실패한 호출의 4번째 실행, 무언가 바뀌면 풀림
game-trap-guard blocked this call: it prints a .env file into the conversation (.env). …
game-barrier blocked this call: it discards uncommitted changes (git reset --hard). …
game-loop-breaker blocked this call: `ls /nonexistent-dir-xyz` already failed the same way 3 times …

02  ·  P1 안전과 비용 · HUD · 세이브 포인트04 / 08

HP는 컨텍스트, 세이브는 내일의 나에게

입력창 위 HUD가 남은 컨텍스트(HP), 요금제 한도(MP), 세션 비용(G, 기본 ₩)을 늘 보여 주고, HP가 낮아지면 휴식(/compact)과 세이브(/save) 버튼을 띄웁니다. /save는 한 일·남은 일·결정·파일·재개 프롬프트를 세이브 화면으로 남기고 패스워드를 클립보드에 복사합니다.

녹화 세션 1:50–2:04 · /save → 세이브 화면 · PASSWORD COPIED · HUD SAVED · ★ 첫 세이브
Fig. 03 — /save 세이브 화면 (GIF)
다음 세션 시작
Fig. 04 — 타이틀 화면 · HUD · EQUIP · MAP · STANCE
  • HUD — LV · EXP · HP · MP · G, 상태 태그(READY · HP LOW! · REST · SAVED · LEVEL UP!)
  • 전투 로그 — TURN, HIT · CRIT · MISS · BLOCK, COMBO ×n → BREAK, 편집 +추가 −삭제 줄 수
  • 세이브 포인트 — 프로젝트당 5칸, /load 패스워드로 다른 프로젝트에서도 이어 하기, 세이브가 있는 폴더는 타이틀 화면(CONTINUE · NEW GAME · LOAD)으로 시작
  • 효과음 — 질문 대기, 긴 턴 종료, 가드 거부, 세이브 때 8비트 효과음 (macOS · Windows · Linux)

지금 무엇을 하고, 얼마가 들고, 어디까지 왔나

스피너는 지금 실행 중인 호출과 이번 턴 비용을, 하단 배지는 권한 모드를, 상태줄은 브랜치와 플레이 시간을 보여 줍니다. 서브에이전트, 할 일 목록, 파일 탐색 현황은 오른쪽 패널(PARTY · QUEST · MINIMAP)로 엽니다.

모호한 지시와 추측을 눈에 보이게

‘적당히’ 같은 모호한 말은 입력하는 순간 밑줄이 그어지고, 완료 조건 없는 지시에는 Claude가 끝나는 기준부터 적습니다. 답변 속 추측 문장에는 [?]가 붙어 확인된 사실과 가설이 구분됩니다.

P4 · CHOICE 답변이 [상태 요약]으로 끝나면 재개 프롬프트가 입력창 제안(Tab)이 되고, 결정 항목은 입력창 위 버튼(다음 할 일 결정, Q1. …)이 됩니다. 고를 때마다 문장이 붙고, 모두 고르면 한 문단으로 다듬어집니다. Jev(typesafe.ai)가 뒤에서 순위를 매기지만 기본 섀도 모드에서는 확률을 숨기고 기록만 합니다. Jev 기능에는 TYPESAFE_API_KEY가 필요하고 요약이 외부로 전송되므로, 비공개 작업에서는 끌 수 있습니다.

설정 (/plugin configure)
  • intensity: off · casual(기본) · hardcore
  • palette: nes(기본) · gameboy · amber · theme
  • currency: krw(기본, 1 USD = 1,400원) · usd
  • 가드 mode: block(기본) · warn · off
가드 해제는 사람만 pass는 다음 거부 1건을 10분 안에 한 번만 통과시킵니다. pass · warn · off는 사람이 직접 입력했을 때만 받아들이므로, Claude가 명령을 실행해 가드를 스스로 풀 수 없습니다.
